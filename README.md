# Matthew Webb Personal Portfolio

A five-page personal portfolio website built for a web development final project.

## Pages

- Home (`index.html`)
- About (`about.html`)
- Education & Experience (`education.html`)
- Projects (`projects.html`)
- Contact (`contact.html`)

## Features

- Responsive navigation
- Five distinct page layouts
- Shared CSS folder and JavaScript folder
- Dark mode toggle
- Project filter buttons
- Contact form validation message

## Before Submitting

1. Replace placeholder email, GitHub, and LinkedIn links on `contact.html`.
2. Add any screenshots or personal images to the `images` folder if desired.
3. Test every page in a private/incognito window after publishing on GitHub Pages.
